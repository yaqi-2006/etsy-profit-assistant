# 演示视频上线后的第一轮推广

**状态：以下外部发布内容均为草稿，尚未发布到 YouTube、社交平台或社区。** 已确认的授权仅覆盖现有 Netlify 免费站点同步新版界面与视频。

## 推荐先做什么

1. 先分享视频页 `https://profit-pilot-etsy-demo.netlify.app/watch/`，观看后可直接进入合成样例试玩。
2. 如果你有自己的 YouTube 频道，确认频道和发布可见性后上传同一份字幕视频，使用下方标题、封面和说明。上传与公开发布需单独确认。
3. 再选一个你已经参与、且当前规则明确允许工具演示的位置发一次反馈邀请，先找 3–5 名自愿者。不要批量私信或抓成员名单，不在禁止工具调研／推广的社区发帖。没有逐一核对的社区不视为已获许可。
4. 先问“哪一步不清楚、是否愿意再用”，不投付费广告，不扩账号／问卷／邮箱收集。浏览量不是已验证需求。

## 不夸大的验收标准

- 记录实际回复、完成样例的人数和具体困惑；没有数据时不写转化率、用户数、节省时间或利润提升。
- 首轮只试玩合成数据，不将其称为真实店铺财务验证。
- 没有主动同意，不把反馈者加入长期营销名单。
- Netlify 免费托管的带宽与请求量会消耗平台额度；视频约 9.2 MB。点击前不预加载全片，不自动播放。暂未增加分析脚本，也不能据此声称已经有曝光或转化。
