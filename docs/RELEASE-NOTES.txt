Limitations:
Real-shop Etsy export compatibility has not been verified. Only the documented
historical English/USD monthly-statement profile and normalized generic event schema
are supported. No automatic Etsy sync, no Chrome Web Store listing, no Etsy affiliation.
Edge installation guidance is provided; Edge extension execution was not tested.
User inputs are not retained by the app after refresh. Downloaded files remain on disk;
HTML/CSV reports are not resumable session backups. The app does not provide secure erasure.
